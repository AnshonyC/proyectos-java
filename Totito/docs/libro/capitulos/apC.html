Apéndice CAtajos de NetBeans

Los atajos de teclado de NetBeans que más tiempo ahorran, agrupados por tarea. Con una docena de ellos en los dedos programarás el doble de rápido.

Son los del mapa de teclas por defecto de NetBeans en Windows. Si alguno no responde, revisa Tools → Options → Keymap (allí se ven y se cambian todos) o consulta Help → Keyboard Shortcuts Card, la tarjeta oficial de atajos. Si usas un portátil, puede que las teclas F1–F12 necesiten la tecla Fn.

Escribir código

AtajoQué haceEjemplo en el Totito
Ctrl+EspacioAutocompletar: propone nombres de clases, métodos y variables.Escribe Tema. y pulsa Ctrl+Espacio: aparecen ROSA, AZUL, fuente(…)…
Ctrl+PMuestra qué parámetros espera el método donde está el cursor.Dentro de BotonNeon.pildora(, recuerda el orden: texto, icono, desde, hasta, ancho, alto.
Ctrl+Shift+EspacioMuestra la documentación (Javadoc) de lo que hay bajo el cursor.Sobre trazoNeon verás su comentario /** … */.
Alt+EnterMuestra las sugerencias de la bombilla: crear el método que falta, agregar el import, atrapar la excepción…Sobre una línea subrayada en rojo.
Ctrl+Shift+IArregla los import: agrega los que faltan y quita los que sobran.Tras pegar código que usa Color o JPanel.
Alt+InsertGenerar código: constructor, getters y setters, toString, métodos a sobrescribir.En Jugador, genera los dos getters de un golpe.
Alt+Shift+FFormatea: arregla sangrías y espacios de todo el archivo (o de lo seleccionado).Después de pegar un bloque desordenado.
Ctrl+/Comenta o descomenta las líneas seleccionadas con //.Para «apagar» un momento una línea mientras pruebas.
Ctrl+EBorra la línea actual.
Ctrl+Shift+↑ / Ctrl+Shift+↓Duplica la línea (o la selección) hacia arriba / abajo.Para escribir las constantes de colores de Tema una debajo de otra.
Alt+Shift+↑ / Alt+Shift+↓Mueve la línea (o la selección) arriba / abajo.Reordenar los agregar(...) de una pantalla.
Ctrl+Z / Ctrl+YDeshacer / rehacer.
Ctrl+S / Ctrl+Shift+SGuardar el archivo / guardar todos.

Plantillas de código: escribe y pulsa Tab

EscribeSe convierte en
sout + TabSystem.out.println("");
soutv + TabSystem.out.println("variable = " + variable); con la variable más cercana
psvm + Tabpublic static void main(String[] args) { }
fori + TabUn for (int i = 0; i < …; i++)
fore + TabUn for-each sobre el arreglo o la lista más cercanos

La lista completa está en Tools → Options → Editor → Code Templates, y allí puedes crear las tuyas.

Moverse por el código

AtajoQué hace
Ctrl+clic (o Ctrl+B)Ir a la definición: salta a la clase, método o variable sobre la que haces clic. Funciona hasta con las clases del JDK (JButton).
Alt+F7Buscar usos: dónde se llama a ese método o se usa esa clase.
Ctrl+OIr a una clase escribiendo su nombre (basta con las mayúsculas: PB encuentra PantallaBase).
Alt+Shift+OIr a un archivo por su nombre.
Ctrl+GIr a un número de línea (útil cuando un error dice Partida.java:62).
Ctrl+[Salta a la llave o paréntesis que hace pareja con el que está junto al cursor.
Ctrl+TabCambiar entre los archivos abiertos.
Ctrl+WCerrar la pestaña actual.
Shift+EscMaximiza la ventana actual (por ejemplo, el editor) o la devuelve a su tamaño.
Ctrl+1 / Ctrl+2Ventana Projects / Files.
Ctrl+4Ventana Output (la salida del programa y de la compilación).
Ctrl+7Ventana Navigator: la lista de métodos y campos del archivo abierto.

Buscar y renombrar

AtajoQué hace
Ctrl+F / Ctrl+HBuscar / reemplazar en el archivo abierto.
F3 / Shift+F3Siguiente / anterior resultado de la búsqueda.
Ctrl+Shift+FBuscar en todo el proyecto (por ejemplo, todos los usos de Tema.MORADO).
Ctrl+Shift+HReemplazar en todo el proyecto.
Ctrl+RRenombrar: cambia el nombre de una variable, método o clase en todos los lugares donde se usa (y el archivo, si es una clase). Mucho más seguro que buscar y reemplazar.

Compilar, ejecutar y probar

AtajoQué hace
F6Run Project: ejecuta la clase principal del proyecto (TotitoApp, la de exec.mainClass).
Shift+F6Run File: ejecuta el main del archivo abierto. Es la forma de probar las clases antes del capítulo 61, cuando aún no existe TotitoApp.
F9Compila solo el archivo abierto.
F11Build Project: compila el proyecto.
Shift+F11Clean and Build Project: borra lo compilado y compila todo de cero (y crea el .jar).
Alt+F6Test Project: ejecuta todas las pruebas de JUnit (capítulo 69).
Ctrl+F6Test File: ejecuta las pruebas del archivo abierto.

Depurar (capítulo 62)

AtajoQué hace
Ctrl+F8Pone o quita un punto de interrupción en la línea actual (también: clic en el número de línea).
Ctrl+F5Debug Project: ejecuta el proyecto con el depurador.
Ctrl+Shift+F5Debug File: depura el main del archivo abierto.
F8Step Over: ejecuta la línea y pasa a la siguiente, sin entrar en los métodos que llama.
F7Step Into: entra en el método que se llama en la línea.
Ctrl+F7Step Out: termina el método actual y vuelve a quien lo llamó.
F4Run to Cursor: sigue hasta la línea donde está el cursor.
F5Continue: sigue hasta el próximo punto de interrupción.
Shift+F5Termina la sesión de depuración.

Proyectos y archivos

AtajoQué hace
Ctrl+Shift+NProyecto nuevo.
Ctrl+Shift+OAbrir un proyecto (como la carpeta Totito).
Ctrl+NArchivo nuevo (una clase, una interfaz…).
Aprende tres por semana Nadie memoriza una tabla. Elige tres atajos, pégalos en un papel junto al monitor y oblígate a usarlos una semana. Los que más rinden al principio: Ctrl+Espacio, Alt+Enter y Alt+Shift+F.
