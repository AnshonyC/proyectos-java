Apéndice AChuleta de PowerShell

Los comandos de PowerShell que usa el libro, y algunos más que te harán la vida fácil, agrupados por tarea. Todos funcionan en el PowerShell que viene con Windows 10 y 11 (Windows PowerShell 5.1).

Convenciones: lo que está entre < y > se reemplaza por tu valor (sin los signos). Los comandos del proyecto se ejecutan desde $HOME\Proyectos\Totito. Entre paréntesis va el alias corto cuando existe: es otro nombre para el mismo comando (capítulo 3).

Moverse por las carpetas

ComandoQué hace
Get-Location (pwd)Muestra en qué carpeta estás.
Set-Location <ruta> (cd)Entra en una carpeta. cd .. sube un nivel; cd ~ o cd $HOME va a tu carpeta de usuario; cd \ va a la raíz del disco.
cd $HOME\Proyectos\TotitoIr a la carpeta del proyecto del libro.
Get-ChildItem (ls, dir)Lista el contenido de la carpeta.
Get-ChildItem -ForceIncluye los ocultos, como .git.
Get-ChildItem -Path src -Recurse -Filter *.javaTodos los .java de src y sus subcarpetas.
Invoke-Item . (ii .)Abre la carpeta actual en el Explorador de archivos.
Test-Path <ruta>Responde True o False: ¿existe esa ruta?

Crear, copiar, mover y borrar

ComandoQué hace
New-Item -ItemType Directory <carpeta> (mkdir)Crea una carpeta. Con -Force crea también las intermedias y no se queja si ya existe.
New-Item <archivo>Crea un archivo vacío, por ejemplo New-Item src\Tablero.java.
Copy-Item <origen> <destino> (cp)Copia. Para copiar una carpeta con todo su contenido, agrega -Recurse.
Move-Item <origen> <destino> (mv)Mueve o renombra.
Rename-Item <archivo> <nombre-nuevo>Renombra (solo el nombre, sin ruta).
Remove-Item <archivo> (rm, del)Borra. No pasa por la Papelera.
Remove-Item -Recurse -Force <carpeta>Borra una carpeta con todo lo que tiene. Revisa dos veces la ruta antes de pulsar Enter.
Remove-Item -Recurse -Force target, outLimpia lo compilado del Totito (se regenera al compilar).
Prueba antes de borrar Agrega -WhatIf al final de cualquier Remove-Item, Move-Item o Copy-Item: PowerShell describe lo que haría, sin hacerlo. Si la lista es la que esperabas, repite el comando sin -WhatIf.

Ver y buscar dentro de archivos

ComandoQué hace
Get-Content <archivo> (cat, type)Muestra el contenido.
Get-Content <archivo> -Tail 20Solo las últimas 20 líneas.
Get-Content -Encoding UTF8 <archivo>Lee el archivo como UTF-8 (para que las tildes se vean bien).
Select-String -Path src\*.java -Pattern "Tema.ROSA"Busca un texto en varios archivos y muestra archivo, número de línea y línea. Es el «buscar» de la terminal.
(Get-Content src\Partida.java).CountCuántas líneas tiene un archivo.
notepad <archivo>Abre el archivo en el Bloc de notas.
code .Abre la carpeta en Visual Studio Code (si lo instalaste).

Comprimir y comprobar

ComandoQué hace
Compress-Archive -Path dist\app\Totito -DestinationPath dist\Totito-1.0.0-portable.zipCrea un zip (capítulo 65). Con -Force reemplaza uno anterior.
Expand-Archive <archivo.zip> -DestinationPath <carpeta>Descomprime.
Get-FileHash <archivo>Calcula la huella SHA-256 de un archivo, para comprobar que una descarga no se alteró.
(Get-Item <archivo>).Length / 1MBTamaño del archivo en megabytes.

Variables, entorno y PATH

ComandoQué hace
$HOMETu carpeta de usuario, C:\Users\<tu-usuario>.
$origen = "$HOME\Proyectos\Totito"Guarda un valor en una variable. Con comillas dobles, las variables de dentro se reemplazan; con simples, no.
$env:JAVA_HOMEMuestra la variable de entorno JAVA_HOME (capítulo 4).
$env:Path -split ";"Muestra el PATH, una carpeta por línea.
Get-Command javaDice qué java.exe se ejecuta al escribir java (la primera carpeta del PATH que lo tiene).
where.exe javaLista todos los java.exe que hay en el PATH, en orden. Útil si hay dos JDK.
[Environment]::SetEnvironmentVariable("JAVA_HOME", "<ruta-del-jdk>", "User")Fija JAVA_HOME de forma permanente para tu usuario. Cierra y vuelve a abrir PowerShell para verla.
[guid]::NewGuid()Genera un identificador único nuevo, como el de --win-upgrade-uuid (capítulo 66).

Instalar programas con winget

ComandoQué hace
winget search <texto>Busca programas por nombre.
winget show --id <id> -eMuestra la información de un paquete (versión, editor, dependencias).
winget install --id <id> -eInstala. -e exige el identificador exacto.
winget listLista lo instalado. winget list Temurin filtra por nombre.
winget upgradeLista lo que tiene versión nueva; winget upgrade --id <id> -e actualiza uno.
winget uninstall --id <id> -eDesinstala.

Los programas del libro, en el orden en que se instalan (capítulo 4). El JDK va primero, y NetBeans lleva --skip-dependencies: su paquete declara como dependencia otro JDK (BellSoft Liberica 23) y, sin esa opción, winget lo instalaría también y tendrías dos Java distintos.

winget install --id EclipseAdoptium.Temurin.21.JDK -e
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id Apache.NetBeans -e --skip-dependencies
winget install --id WiXToolset.WiXToolset -e
# Opcionales
winget install --id Microsoft.VisualStudioCode -e
winget install --id Microsoft.WindowsTerminal -e
winget install --id JRSoftware.InnoSetup -e
Después de instalar, cierra PowerShell El PATH se lee al abrir la ventana. Si java, git o gh «no se reconocen» justo después de instalarlos, cierra todas las ventanas de PowerShell y abre una nueva.

Java y el Totito

ComandoQué hace
java -version · javac -versionComprueban el JDK. Deben decir 21.
javac -encoding UTF-8 -d out src\*.javaCompila todo el Totito en la carpeta out.
java -cp out TotitoAppEjecuta el juego compilado con javac (desde el capítulo 61).
java -cp target\classes <Clase>Ejecuta cualquier clase con main que NetBeans ya compiló (Clean and Build). Es la forma de probar las clases antes del capítulo 61, cuando aún no existe TotitoApp; en NetBeans, lo mismo es clic derecho → Run File (Shift+F6).
java -cp target\classes herramientas\PruebaConsola.javaEjecuta una herramienta (también VistaPrevia.java y GeneradorIcono.java).
java -cp out JuegoMainAbre la ventana sencilla de la versión 0.1.
java -jar target\Totito-1.0-SNAPSHOT.jarEjecuta el .jar (capítulo 63).
jar tf target\Totito-1.0-SNAPSHOT.jarLista lo que hay dentro del .jar.
jdeps --print-module-deps target\Totito-1.0-SNAPSHOT.jarQué módulos de Java necesita: java.base,java.desktop.
jshellConsola para probar trozos de Java (capítulo 11). Se sale con /exit.
jpackage --type app-image …Carpeta portable con Totito.exe (capítulo 65; el comando completo está allí).
jpackage --type exe …Instalador (capítulo 66).

La preparación del empaquetado, tal como en los capítulos 63 a 65:

New-Item -ItemType Directory -Force dist\entrada | Out-Null
Copy-Item target\Totito-1.0-SNAPSHOT.jar dist\entrada\
.\dist\app\Totito\Totito.exe

La última línea abre el programa portable ya generado. El .\ del principio es obligatorio: PowerShell no ejecuta programas de la carpeta actual si no se lo indicas así.

Trucos del teclado en la terminal

TeclaQué hace
TabCompleta nombres de comandos, carpetas y archivos. Pulsa varias veces para ver las opciones.
↑ / ↓Recorre los comandos que ya escribiste.
Ctrl+RBusca hacia atrás en el historial mientras escribes.
Ctrl+CDetiene el comando que se está ejecutando (o borra la línea que escribías).
Clic derechoPega lo copiado (en la ventana clásica de PowerShell). En Windows Terminal también sirve Ctrl+V.
clsLimpia la pantalla.
Get-HistoryLista los comandos de la sesión.

Pedir ayuda a la propia terminal

ComandoQué hace
Get-Help <comando> -ExamplesEjemplos de uso de un comando, por ejemplo Get-Help Copy-Item -Examples. La primera vez puede pedirte Update-Help.
Get-Command *archive*Busca comandos cuyo nombre contenga un texto.
<programa> --helpCasi todos los programas externos explican sus opciones así: git --help, gh --help, jpackage --help.
