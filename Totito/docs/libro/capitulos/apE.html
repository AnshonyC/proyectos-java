Apéndice EGlosario

Los términos de Java, programación orientada a objetos, Swing, Git, diseño y distribución que aparecen en el libro, en orden alfabético, con una definición corta y el capítulo donde se explican a fondo.

Los nombres que empiezan con un punto o una arroba (.gitignore, @Override) se ordenan por su primera letra. Las palabras en cursiva dentro de una definición tienen su propia entrada.

A

  • Acoplamiento: Cuánto depende una clase de otras. Se busca que sea bajo: el kit neón del Totito compila sin ninguna clase del juego y por eso se puede llevar a otros proyectos (capítulos 27 y 68).
  • Alcance: La zona del código donde una variable existe. Una variable declarada dentro de un for o de un método deja de existir al salir de él (capítulo 16).
  • Alfa: El cuarto componente de un color, que indica su opacidad: 0 es invisible y 255 opaco. Tema.conAlfa cambia el alfa de un color (capítulo 35).
  • Algoritmo: Una receta de pasos precisos para resolver un problema. Minimax es el algoritmo con el que la IA del Totito elige su jugada.
  • Anotación: Una marca que empieza con @ y da información extra al compilador o a una herramienta, sin cambiar el código: @Override, @FunctionalInterface, @Test.
  • Antialiasing (suavizado): Técnica que suaviza los bordes de líneas y letras pintando píxeles intermedios, para que no se vean «en escalera». Dibujo.preparar la activa.
  • API: (Application Programming Interface) El conjunto de clases y métodos que una librería ofrece para que otros los usen. La API de Swing incluye JButton, JPanel…
  • Área de preparación: (staging area) La zona de Git donde se ponen, con git add, los cambios que entrarán en el próximo commit (capítulo 6).
  • Argumento: El valor concreto que se pasa a un método al llamarlo. En marcarCasilla(1, 2, 'X'), los argumentos son 1, 2 y 'X'. Ver también parámetro.
  • Arreglo: (array) Una fila de casillas del mismo tipo y tamaño fijo, numeradas desde 0: int[] victorias = new int[2]. Un arreglo de arreglos es una matriz, como char[][] casillas (capítulo 15).
  • Asignación: Guardar un valor en una variable con el signo =: turno = 1 - turno;. No es una comparación; comparar es ==.

B

  • BigDecimal: Clase de Java que guarda números decimales exactos. Se usa para dinero y calculadoras, donde double comete pequeños errores (0.1 + 0.2) (capítulo 68).
  • Bloque: Un grupo de instrucciones entre llaves { }. El cuerpo de una clase, de un método, de un if o de un for es un bloque.
  • boolean: Tipo de dato que solo puede valer true (verdadero) o false (falso). Lo devuelven las comparaciones y lo usan los if.
  • BorderLayout: Layout de Swing que reparte el espacio en cinco zonas: norte, sur, este, oeste y centro. PantallaBase pone el Encabezado en el norte (capítulo 37).
  • BoxLayout: Layout de Swing que coloca los componentes uno debajo de otro (o uno al lado de otro). Es el que usan las pantallas del Totito para apilar tarjetas y botones.
  • Bytecode: El código intermedio que produce javac en los archivos .class. No es de ninguna computadora concreta: lo ejecuta la JVM (capítulo 11).

C

  • Campo: Una variable que pertenece a un objeto (o a la clase, si es static) y vive mientras él viva. Partida tiene campos como tablero, turno y estado. También se llama atributo.
  • CardLayout: Layout de Swing que apila varios paneles como un mazo de cartas y muestra uno a la vez. PanelPrincipal lo usa para cambiar de pantalla.
  • Casting: Convertir un valor de un tipo a otro escribiendo el tipo entre paréntesis: (int) Math.floor(x), (Graphics2D) g (capítulo 12).
  • char: Tipo de dato que guarda un solo carácter, entre comillas simples: 'X', 'O', ' '. Las casillas del Totito son char.
  • Ciclo: (o bucle) Instrucción que repite un bloque mientras se cumpla una condición: for, while, do-while y el for-each (capítulo 14).
  • Clase: El molde que describe cómo son y qué saben hacer un tipo de objetos: sus campos y sus métodos. Tablero es una clase; cada new Tablero() crea un objeto (capítulo 18).
  • Clase abstracta: Una clase marcada con abstract que no se puede instanciar directamente: existe para que otras hereden de ella. PantallaBase es abstracta (capítulo 24).
  • Clase anónima: Una clase sin nombre que se define y se instancia en el mismo lugar, para usarla una sola vez. El MouseAdapter de PanelTablero es una (capítulo 25).
  • Clase interna: Una clase escrita dentro de otra. Puede usar los campos de la clase que la contiene. LimiteDeLargo está dentro de CampoTexto (capítulo 25).
  • Clonar: Descargar una copia completa de un repositorio remoto, con todo su historial: git clone o gh repo clone.
  • Código fuente: El texto que escribe el programador, en archivos .java. La computadora no lo ejecuta directamente: primero se compila.
  • Cohesión: Cuánto se relacionan entre sí las tareas de una clase. Se busca que sea alta: Tema solo se ocupa del aspecto, Tablero solo de las casillas (capítulo 27).
  • Commit: Una foto guardada del proyecto en Git, con un mensaje, un autor, una fecha y un identificador único. El historial es la cadena de commits (capítulo 6).
  • Compilador: El programa que traduce el código fuente a algo ejecutable. En Java es javac, que produce bytecode y avisa de los errores antes de ejecutar.
  • Componente: Cualquier pieza visible de una interfaz Swing: un botón, una etiqueta, un panel. Todos heredan de JComponent.
  • Composición: Una relación «tiene-un» entre clases: un objeto guarda a otros en sus campos. Partida tiene un Tablero y dos Jugador (capítulo 21).
  • Concatenar: Unir textos con +: "Turno de " + nombre.
  • Conflicto: Lo que ocurre en Git cuando dos ramas cambiaron las mismas líneas y no puede decidir solo cuál queda. Se resuelve a mano (capítulo 9).
  • Constante: Un valor que no cambia, declarado con static final y escrito en mayúsculas: Tablero.VACIA, PanelPrincipal.ANCHO (capítulo 20).
  • Constructor: Método especial, con el mismo nombre que la clase y sin tipo de retorno, que prepara un objeto recién creado con new (capítulo 20).
  • Contraste: La diferencia de luminosidad entre un texto y su fondo. Con poco contraste el texto cuesta leerse; las pautas de accesibilidad piden un mínimo (capítulo 35).

D

  • Degradado: Un relleno que pasa gradualmente de un color a otro. GradientPaint pinta el fondo del Totito de violeta oscuro a casi negro.
  • Dependencia: Una librería ajena que tu proyecto necesita, declarada en el pom.xml para que Maven la descargue. JUnit y el driver de SQLite son dependencias (capítulo 69).
  • Depurador: Herramienta que ejecuta el programa paso a paso, deteniéndose en puntos de interrupción, para ver el valor de cada variable en cada momento (capítulo 62).
  • double: Tipo de dato para números con decimales. Es rápido, pero guarda algunos valores con un pequeño error de redondeo.

E

  • EDT: (Event Dispatch Thread, hilo de eventos) El único hilo desde el que se debe tocar la interfaz Swing. Por eso main crea la ventana dentro de SwingUtilities.invokeLater (capítulo 37).
  • Encapsulamiento: Ocultar los datos de un objeto (private) y dejar que se cambien solo a través de sus métodos, que cuidan las reglas. Nadie puede poner una ficha en una casilla ocupada saltándose marcarCasilla (capítulo 19).
  • Enlace dinámico: Mecanismo por el que Java decide, mientras el programa corre, qué versión de un método sobrescrito ejecutar según el objeto real. Es lo que hace funcionar el polimorfismo (capítulo 23).
  • enum: Un tipo con una lista cerrada de valores con nombre: Partida.Estado solo puede ser EN_CURSO, VICTORIA o EMPATE (capítulo 26).
  • Etiqueta: (tag) Un nombre fijo que Git pone a un commit concreto, normalmente una versión: v1.0.0.
  • Excepción: Un objeto que representa un error ocurrido mientras el programa corre. Se lanza con throw y se atrapa con try/catch; si nadie la atrapa, el programa se detiene (capítulo 26).
  • Excepción comprobada: Una excepción que Java obliga a manejar o declarar con throws, como IOException. Las que heredan de RuntimeException no lo exigen.
  • extends: Palabra con la que una clase hereda de otra: class BotonNeon extends JButton.

F

  • final: Modificador que impide cambiar algo: una variable final no se reasigna, un método final no se sobrescribe y de una clase final no se hereda (capítulo 20).
  • Firma de código: Un sello digital, comprado a una entidad certificadora, que prueba quién hizo un programa y que no se alteró. Evita el aviso de SmartScreen (capítulo 67).
  • Firma de un método: Su nombre y la lista de tipos de sus parámetros. Dos métodos con el mismo nombre y distinta firma son una sobrecarga.
  • Fork: Una copia de un repositorio ajeno en tu propia cuenta de GitHub, para cambiarlo y proponer los cambios con un Pull Request (capítulo 10).

G

  • Getter: Un método que devuelve el valor de un campo privado, como getNombre(). Su pareja es el setter.
  • gh: GitHub CLI: el programa de línea de comandos para trabajar con GitHub (repositorios, PR, issues, Releases) sin abrir el navegador.
  • Git: Sistema de control de versiones: guarda la historia completa de un proyecto en commits y permite volver atrás, trabajar en ramas y colaborar (capítulo 6).
  • GitHub: Sitio web que aloja repositorios de Git y añade colaboración: Pull Requests, issues, Releases, perfiles.
  • .gitignore: Archivo con los patrones de archivos que Git debe ignorar, como target/ o out/ (capítulo 5).
  • Graphics2D: El «pincel» de Java2D: el objeto con el que paintComponent dibuja líneas, formas, textos y degradados (capítulo 37).
  • GridLayout: Layout de Swing que coloca los componentes en una cuadrícula de celdas iguales. Ideal para el teclado de una calculadora (capítulo 68).

H

  • HEAD: En Git, el puntero que indica en qué commit (y rama) estás trabajando ahora.
  • Herencia: Relación «es-un»: una clase hija recibe los campos y métodos de su madre y puede agregar o cambiar comportamiento. TarjetaJugador es una Tarjeta (capítulo 22).
  • Hexadecimal: Sistema de numeración de base 16 (dígitos 0–9 y A–F). Los colores se escriben así: #FF3BD4 es el rosa del Totito (capítulo 35).

I

  • IDE: (entorno de desarrollo integrado) Un programa que reúne editor, compilador, ejecución y depurador. NetBeans es un IDE.
  • if: Instrucción de decisión: ejecuta un bloque solo si la condición es verdadera, y opcionalmente otro con else (capítulo 13).
  • implements: Palabra con la que una clase se compromete a cumplir una interfaz: PanelPrincipal implements Navegacion.
  • import: Línea al principio de un archivo que permite usar una clase de otro paquete por su nombre corto: import javax.swing.JPanel;.
  • Instalador: Un programa que copia otro programa en la computadora, crea sus accesos directos y lo registra para poder desinstalarlo. El del Totito se crea con jpackage y WiX (capítulo 66).
  • Instancia: Un objeto concreto creado a partir de una clase. Cada new Jugador(...) es una instancia de Jugador.
  • int: Tipo de dato para números enteros, sin decimales: filas, columnas, victorias.
  • Interfaz (de Java): Un contrato: una lista de métodos que una clase promete tener, sin decir cómo los hace. Navegacion es una interfaz (capítulo 24).
  • Interfaz funcional: Una interfaz con un solo método abstracto, que por eso se puede escribir con una lambda: Iconos.Icono, Runnable.
  • Interfaz gráfica: (GUI) La parte visible de un programa con la que se interactúa con ratón y teclado: ventanas, botones, tableros.
  • Invariante: Una regla que debe cumplirse siempre en un objeto. En Partida, los dos jugadores nunca tienen la misma ficha: el constructor lo garantiza (capítulo 19).
  • Inyección SQL: Ataque que consiste en escribir código SQL en un campo de texto para que la base de datos lo ejecute. Se evita con PreparedStatement (capítulo 69).
  • Issue: En GitHub, una tarea, error o propuesta anotada en un repositorio, con su conversación.

J

  • .jar: Un archivo que empaqueta las clases compiladas de un programa y su manifiesto. Se ejecuta con java -jar (capítulo 63).
  • Java: Lenguaje de programación orientado a objetos cuyo código compilado corre en cualquier sistema que tenga una JVM.
  • javac: El compilador de Java: convierte los .java en .class.
  • JavaFX: Biblioteca gráfica moderna para Java, alternativa a Swing, con estilos CSS. Se instala aparte (capítulo 69).
  • JDBC: La parte de Java que se comunica con bases de datos mediante SQL (capítulo 69).
  • JDK: (Java Development Kit) Lo necesario para programar en Java: compilador, JVM y herramientas como jar, jshell y jpackage. El libro usa Temurin 21.
  • JFrame: La ventana de Swing, con su barra de título. TotitoApp hereda de JFrame.
  • jpackage: Herramienta del JDK que convierte un .jar en un programa nativo (Totito.exe) con su propio Java, y en un instalador (capítulos 65 y 66).
  • JPanel: Un contenedor de Swing: un rectángulo que agrupa componentes y los ordena con un layout.
  • jshell: Consola interactiva de Java para probar instrucciones sueltas sin crear una clase (capítulo 11).
  • JSON: Formato de texto para intercambiar datos entre programas: {"fila":0,"columna":2}.
  • JUnit: La librería de pruebas automáticas más usada en Java (capítulo 69).
  • JVM: (Java Virtual Machine) La máquina virtual que ejecuta el bytecode. Es lo que permite que el mismo .class corra en Windows, Linux o macOS.

L

  • Lambda: Una función corta sin nombre, escrita con flecha: e -> navegacion.irAlMenu(). Se usa donde se espera una interfaz funcional (capítulo 25).
  • Layout: El administrador que decide dónde y de qué tamaño va cada componente dentro de un contenedor: BorderLayout, BoxLayout, CardLayout…
  • Librería: Código ya escrito, empaquetado para usarlo en otros programas. Swing es una librería del JDK; JUnit, una librería externa.

M

  • main: El método por el que empieza un programa Java: public static void main(String[] args).
  • Manifiesto: El archivo META-INF/MANIFEST.MF dentro de un .jar. Su línea Main-Class dice qué clase arranca (capítulo 63).
  • Matriz: Un arreglo de dos dimensiones, con filas y columnas: char[3][3].
  • Maven: Herramienta que construye proyectos Java a partir del pom.xml: compila, ejecuta las pruebas, descarga dependencias y crea el .jar.
  • Merge: Unir en una rama los cambios de otra (capítulo 9).
  • Método: Un bloque de código con nombre que una clase sabe ejecutar; lo que en otros lenguajes se llama función. Puede recibir parámetros y devolver un valor con return (capítulo 16).
  • Método de fábrica: Un método static que crea y devuelve objetos, en lugar de llamar directamente al constructor: BotonNeon.menu(...), Rotulo.titulo(...).
  • Minimax: Algoritmo para juegos de dos jugadores que explora las jugadas posibles suponiendo que uno busca el máximo puntaje y el otro el mínimo (capítulo 31).
  • Modificador de acceso: Palabra que decide quién puede usar una clase o miembro: public (todos), protected (el paquete y las subclases), sin modificador (el paquete) y private (solo la propia clase).

N

  • new: Palabra que crea un objeto nuevo llamando a su constructor: new Tablero().
  • null: El valor de una referencia que no apunta a ningún objeto. Usar algo que vale null provoca un NullPointerException.

O

  • Objeto: Una «cosa» concreta del programa, creada a partir de una clase, con sus propios valores en los campos. Cada partida es un objeto Partida.
  • Observer: Patrón de diseño en el que un objeto avisa a otros, que se registraron como «oyentes», cuando ocurre algo. addActionListener y OyenteCasilla lo usan (capítulo 27).
  • @Override: Anotación que indica que un método sobrescribe a uno de la clase madre o de una interfaz. Si no coincide, el compilador avisa.

P

  • paintComponent: El método que Swing llama cuando un componente necesita dibujarse. Se sobrescribe para dibujar a mano, como hacen todos los componentes neón (capítulo 37).
  • Paquete: Un grupo de clases con nombre, que corresponde a una carpeta: javax.swing, totito.logica (capítulo 69).
  • Paquete por defecto: El paquete sin nombre en el que están las clases que no declaran package, como todas las del Totito. Sus clases no se pueden importar desde otros paquetes.
  • Parámetro: La variable que un método declara para recibir un valor: en marcarCasilla(int fila, int columna, char ficha), los parámetros son fila, columna y ficha.
  • PATH: Variable de entorno con la lista de carpetas donde Windows busca los programas que escribes en la terminal (capítulo 4).
  • Patrón de diseño: Una solución probada y con nombre para un problema de diseño que se repite: Observer, Factory, Template Method, Strategy (capítulo 27).
  • Pila de llamadas: La lista de métodos que se están ejecutando, cada uno esperando al que llamó. Se ve en los errores, en las líneas at (capítulo 16).
  • Polimorfismo: La capacidad de tratar objetos de clases distintas a través de un tipo común y que cada uno responda a su manera. Swing llama a paintComponent sin saber si el componente es un BotonNeon o una Tarjeta (capítulo 23).
  • pom.xml: El archivo de configuración de un proyecto Maven: nombre, versión de Java, dependencias y plugins (capítulo 5).
  • PowerShell: La terminal y lenguaje de comandos de Windows que usa el libro (capítulo 3).
  • private: Modificador que hace que un campo o método solo se pueda usar dentro de su propia clase.
  • protected: Modificador que permite el acceso desde el mismo paquete y desde las subclases. Los métodos agregar y espacio de PantallaBase son protected.
  • Prueba automática: Código que ejecuta otro código y comprueba que el resultado es el esperado, sin intervención humana (capítulo 69).
  • public: Modificador que permite usar una clase, campo o método desde cualquier otra clase.
  • Pull: Traer a tu repositorio los commits nuevos del remoto y unirlos con tu rama: git pull.
  • Pull Request: (PR) Propuesta en GitHub para unir los cambios de una rama con otra, con su revisión y conversación (capítulo 10).
  • Punto de interrupción: Una marca en una línea donde el depurador detiene el programa para inspeccionarlo (capítulo 62).
  • Push: Subir tus commits al repositorio remoto: git push.

R

  • Rama: (branch) Una línea de trabajo independiente dentro de un repositorio. El Totito construyó la interfaz en la rama interfaz-neon (capítulo 9).
  • record: Forma corta de declarar en Java una clase de datos inmutable: record Jugada(int fila, int columna) { }.
  • Recursión: Cuando un método se llama a sí mismo para resolver una versión más pequeña del problema. Necesita un caso base que la detenga. minimax es recursivo (capítulo 16).
  • Refactorizar: Cambiar la estructura del código sin cambiar lo que hace, para que quede más claro o más fácil de mantener: renombrar, mover, extraer un método.
  • Referencia: Lo que guarda una variable de tipo objeto: no el objeto, sino «dónde está». Dos variables pueden referirse al mismo objeto (capítulo 18).
  • Regresión: Un error nuevo en algo que antes funcionaba, provocado por un cambio. Las pruebas automáticas existen para detectarlas.
  • Release: En GitHub, una versión publicada de un programa, ligada a una etiqueta y con archivos para descargar, como el instalador (capítulo 67).
  • repaint: Método que pide a Swing que vuelva a dibujar un componente en cuanto pueda. No dibuja en el momento: Swing llamará a paintComponent.
  • Repositorio: La carpeta de un proyecto bajo Git, con todo su historial (en la carpeta oculta .git). Puede estar en tu computadora (local) o en GitHub (remoto).
  • return: Instrucción que termina un método y, si no es void, devuelve un valor a quien lo llamó.
  • RGB: Modelo de color que mezcla rojo, verde y azul, cada uno de 0 a 255. new Color(0xFF, 0x3B, 0xD4) es el rosa del Totito (capítulo 35).

S

  • Semilla: El número con el que arranca un generador de números aleatorios. Con la misma semilla, Random produce siempre la misma secuencia (capítulo 68).
  • SemVer: (versionado semántico) Numerar versiones como MAYOR.MENOR.PARCHE: 1.0.0. Se sube el PARCHE al corregir errores, el MENOR al agregar funciones y el MAYOR al romper la compatibilidad (capítulo 67).
  • Serializar: Convertir un objeto en texto o bytes para guardarlo o enviarlo, y deserializar, el camino inverso. Tarea.aLinea() y Tarea.desdeLinea() lo hacen (capítulo 68).
  • Setter: Un método que cambia el valor de un campo privado, y puede validar el valor antes: setInteractivo(boolean).
  • SmartScreen: El filtro de Windows que avisa al abrir programas descargados que no están firmados o que pocos usuarios han ejecutado (capítulo 67).
  • Sobrecarga: Tener varios métodos con el mismo nombre y distintos parámetros. Dibujo.trazoNeon tiene una versión con intensidad y otra sin ella (capítulo 16).
  • Sobrescritura: Volver a escribir en una clase hija un método heredado, para cambiar su comportamiento. Se marca con @Override (capítulo 23).
  • SQL: El lenguaje con el que se consultan y modifican las bases de datos: SELECT, INSERT, UPDATE, DELETE.
  • static: Modificador que hace que un campo o método pertenezca a la clase y no a cada objeto. Se usa sin crear objetos: Tema.fuente(...) (capítulo 20).
  • String: La clase de Java para textos, entre comillas dobles: "Juego del Totito". Sus objetos no se pueden modificar (capítulo 17).
  • super: Palabra que se refiere a la clase madre: super(texto) llama a su constructor y super.paintComponent(g) a su versión de un método (capítulo 22).
  • Swing: La biblioteca de interfaces gráficas incluida en el JDK, con la que está hecho el Totito.
  • switch: Instrucción que elige entre varios caminos según un valor. La forma con flechas (case MENU -> 30;) además puede devolver un valor (capítulo 13).

T

  • this: Palabra que se refiere al objeto actual. this.nombre = nombre distingue el campo del parámetro (capítulo 20).
  • Timer (de Swing): javax.swing.Timer: ejecuta una acción en el hilo de eventos después de unos milisegundos, una vez o repetidamente. PantallaJuego lo usa para la pausa de la IA.
  • Tipo de dato: Lo que una variable puede guardar y qué operaciones admite: int, double, boolean, char, String, o cualquier clase (capítulo 12).
  • try/catch/finally: Estructura para manejar excepciones: try contiene el código que puede fallar, catch lo que se hace si falla y finally lo que se hace siempre (capítulo 26).

U

  • UTF-8: La codificación de texto que representa cualquier carácter (tildes, ñ, ¡, emojis). El Totito compila con -encoding UTF-8 para que sus textos se vean bien.
  • UUID: Un identificador de 128 bits prácticamente imposible de repetir. jpackage usa uno (--win-upgrade-uuid) para reconocer las versiones de un mismo programa (capítulo 66).

V

  • Variable: Un nombre que guarda un valor de un tipo dado y puede cambiar: int turno = 0; (capítulo 12).
  • Variable de entorno: Un dato con nombre que el sistema operativo ofrece a todos los programas, como PATH o JAVA_HOME (capítulo 4).
  • void: Indica que un método no devuelve ningún valor: public void reiniciar().

W

  • winget: El administrador de paquetes de Windows: instala programas desde la terminal con un comando (capítulo 4).
  • WiX: (WiX Toolset) Conjunto de herramientas para crear instaladores de Windows. jpackage lo necesita para producir el .exe instalador (capítulo 66).
