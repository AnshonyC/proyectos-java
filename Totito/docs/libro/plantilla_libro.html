Java desde cero con el Totito
Edición 1.0 — octubre de 2026

Proyecto de referencia: repositorio proyectos-java, carpeta Totito/. Todo el código del libro es el código real de ese proyecto. Se compiló y se probó antes de escribir cada capítulo.

Herramientas usadas en el libro: Java 21 (Eclipse Temurin), Apache NetBeans 25, Git, GitHub CLI, jpackage, WiX Toolset 3.14 e Inno Setup. Todas son gratuitas.

Puedes usar, copiar y modificar el código del Totito para aprender y para tus propios proyectos.

Antes de empezarPrólogo

Este libro tiene una promesa sencilla: si nunca has programado, al terminarlo habrás construido, con tus propias manos y entendiendo cada línea, un juego completo. Será el totito de toda la vida (el tres en raya), con una interfaz de colores neón, una inteligencia artificial que no pierde nunca y un instalador .exe que podrás mandarle a cualquiera.

No es un libro de recetas. Cada vez que escribamos algo, por pequeño que sea (un punto y coma, una llave, la palabra private), vas a saber qué hace, por qué está ahí y para qué sirve. También vas a ver qué pasaría si no estuviera. El totito es la excusa: lo que de verdad te llevas es la forma de pensar de un programador. Por eso cada capítulo termina con una sección «Aplícalo fuera del Totito», que enseña a usar lo aprendido en una tienda, una escuela, otro juego o cualquier idea que tengas.

El camino tiene nueve partes. Primero preparamos la computadora y aprendemos a usar la terminal y Git, la herramienta que guarda cada paso de tu trabajo. Después vienen los fundamentos de Java y la programación orientada a objetos, siempre con ejemplos del juego. Con esa base escribimos la primera versión del totito: la lógica, una IA y una ventana sencilla. Luego estudiamos diseño, color y cómo dibuja Java, y construimos la versión final, clase por clase. Al final aprendemos a probar, empaquetar, crear el instalador y publicarlo en GitHub, y a llevar todo esto a otros proyectos.

Un consejo antes de empezar: escribe el código, no lo copies y pegues. Al escribirlo te vas a equivocar, el compilador te va a avisar y vas a aprender a leer sus mensajes. Esa es, quizá, la habilidad más valiosa de todas. Si algo no funciona, el apéndice D reúne los errores más comunes y su solución.

Bienvenido. Abre tu computadora y empecemos.
